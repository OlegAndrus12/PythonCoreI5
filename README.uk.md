## Як отримати матеріали

Один раз завантажте курс:

```bash
git clone https://github.com/OlegAndrus12/PythonCoreI5.git
cd PythonCoreI5
```

Перед кожною лекцією отримуйте нові матеріали, перебуваючи в цій папці:

```bash
git pull
```

Входити в акаунт не потрібно: репозиторій публічний. Вперше працюєте з Git або щось пішло не так?
👉 **[Покрокова інструкція: встановлення Git, clone, pull, автентифікація через HTTPS і SSH, типові помилки](GIT_GUIDE.uk.md)**

> Тримайте власні вправи **поза** папкою курсу, тоді `git pull` ніколи не конфліктуватиме з вашими змінами.

## Модулі

```
├── module01/   Типи даних: вбудовані типи, змінність, типізація, пріоритет операторів, колекції, ключові слова, перетворення
```

**Домовленості для всіх модулів:**

- У кожному модулі є `agenda.md` з планом лекції; слайди, якщо вони є, додані як PDF.
- Сторінки `.html` самодостатні: відкривайте їх просто з диска в браузері (подвійний клік по файлу), без сервера та встановлення.
- Кожен результат на HTML-сторінці отримано реальним запуском прикладу на CPython 3.14.3.
- Кожен скрипт запускається окремо: `python module01/strings/basics.py`. `module01/deposit.py` просить ввести дані.

# Модуль 01 — Типи даних

Що таке кожен вбудований тип, що він уміє, і ідеї, які пояснюють більшість несподіванок для початківців:
імена — це посилання, одні об'єкти змінюються на місці, а інші ніколи, і Python перевіряє типи під час
виконання, але ніколи не перетворює їх мовчки.

| ------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| **[visualizer.html](module01/visualizer.html)**         | Введіть `a = [1, "hi", True]`, `b = a`, `a.append(99)`, `del a` і дивіться, як імена вказують на об'єкти в купі (heap) — з лічильниками посилань, інтернуванням малих чисел, збиранням сміття та байткодом кожного рядка |
